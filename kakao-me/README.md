# 나에게 보내기 (카카오톡)

내 컴퓨터에서 적은 글을 카카오톡 **나와의 채팅**으로 보내 주는 작은 앱이에요.

## 준비물
- **Node.js** (한 번만 설치): https://nodejs.org 에서 LTS 버전을 받아 설치해요.

## 실행하기
1. 이 `kakao-me` 폴더를 내 컴퓨터에 둬요.
2. 폴더에서 터미널(윈도우는 명령 프롬프트)을 열고 아래를 입력해요.
   ```
   node server.js
   ```
3. 브라우저에서 http://localhost:3000 을 열어요.
4. 화면에 나오는 1, 2, 3단계를 따라 하면 끝이에요.

## 알아 두면 좋은 점
- 앱 키와 로그인 정보는 이 폴더의 `config.json`에만 저장돼요. 다른 사람에게 보내지 마세요. (깃허브에는 올라가지 않아요)
- 한 번 로그인하면 약 두 달 동안 다시 로그인할 필요가 없어요.
- 한 번에 200자까지 보낼 수 있어요.
