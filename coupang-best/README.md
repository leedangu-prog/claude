# 쿠팡 베스트 조회기

카테고리별 쿠팡 베스트 상품과 검색 결과를 보여주고, 각 상품의 판매자 정보를 어디서 확인하는지 안내하는 웹앱이에요.

## 실행 방법
1. [쿠팡 파트너스](https://partners.coupang.com)에 가입하고 승인을 받은 뒤, **추가기능 → 오픈 API**에서 Access Key와 Secret Key를 받아요.
2. `config.example.json`을 복사해 `config.json`으로 이름을 바꾸고 키 두 개를 적어요. (`config.json`은 GitHub에 올라가지 않아요.)
3. 이 폴더에서 `node server.js`를 실행하고 브라우저로 http://localhost:3000 을 열어요. (Node.js 18 이상)

키가 없으면 예시 데이터로 화면만 보여줘요.

## 참고
- 쿠팡 파트너스 API는 판매자 정보(상호, 사업자번호 등)를 주지 않아요. 그래서 판매자 정보는 상품 페이지 아래쪽 "판매자 정보" 칸에서 확인하도록 안내해요.
- 상품 링크는 파트너스 링크라서, 이 링크로 구매가 일어나면 파트너스 수익이 생길 수 있어요.
