가전디지털 베스트

    진짜 순위 보는 법

    쿠팡은 자동 조회를 막고 있어서, 쿠팡 파트너스에서 받은 열쇠(API 키)로 내 컴퓨터에서 실행해야 해요.

    1. 쿠팡 파트너스(partners.coupang.com)에 가입하고 승인을 받아요.
    2. 파트너스 화면의 추가기능 → 오픈 API에서 Access Key와 Secret Key를 받아요.
    3. 이 앱 폴더에 있는 config.example.json을 복사해서 config.json으로 이름을 바꾸고 키 두 개를 적어요.
    4. 폴더에서 아래 명령을 실행하고, 브라우저로 http://localhost:3000을 열어요.
    node server.js

    키는 내 컴퓨터 안에만 있고 밖으로 공유되지 않아요. 쿠팡 파트너스 API는 판매자 정보를 주지 않기 때문에, 판매자 정보는 상품 페이지에서 확인하는 방법을 안내해요.
